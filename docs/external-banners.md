# Автоматические баннеры внешних каталогов

Главная страница объединяет два независимых источника:

- `GET /api/banners` — активные ручные баннеры из таблицы `banners`.
- `GET /api/banners/external` — кандидаты из включённых внешних API. В режиме
  каталога Vibix используются Vibix и VideoSeed; Kodik добавляет кадры аниме и дорам
  независимо от режима основного каталога. Без настроенного ключа API не вызывается.

Кандидаты выбираются из небольшого окна популярных записей Vibix, соответствующих
записей VideoSeed (или его каталога, если совпадений с кадрами нет), первых записей
Kodik. Это подборка до 9 слайдов, а не выгрузка всех изображений каталогов.
Метаданные и одновременные запросы кэшируются на 5 минут; VideoSeed дополнительно
использует свой кэш, чтобы не расходовать дневную квоту при каждом открытии главной.

URL изображений не скачиваются бэкендом. Браузер проверяет реальные naturalWidth /
naturalHeight: минимум 640×360, пропорции 16:9 с допуском 0.05 по отношению сторон.
Вертикальные постеры, широкоформатные кадры, ошибки и таймауты пропускаются.
Для каждого слайда проверяется до трёх URL, не больше трёх слайдов параллельно.
Относительные имена VideoSeed `thumb003.jpg` не превращаются в выдуманные URL.
У сериалов VideoSeed используются доступные превью первых серий первого сезона.
API-ключи и iframe-токены не включаются в ответ с баннерами.

Автобаннеры загружаются после открытия главной и не задерживают серверный рендер.
Слайд ведёт на соответствующую карточку, VideoSeed-ссылка сохраняет `source=videoseed`.
Ручные баннеры идут первыми. Неработающие изображения убираются из карусели.

В админке `/cinema/banners` есть предпросмотр кандидатов с проверкой размеров.
Чтобы оставить только автоматические баннеры, нужно выключить «Активен» у своих
ручных баннеров. Удалять записи не нужно. Автоподбор ничего не создаёт и не меняет
в таблице `banners`, существующие статусы не переключает. Главную после изменения
нужно перезагрузить; ручные баннеры имеют прежний кэш фронта до 60 секунд.
